# TETHER — Product Frontend v2

Production-ready React + TypeScript + Vite + GSAP ScrollTrigger + Lenis + Tailwind CSS frontend for **TETHER**, engineered as a live startup developer control plane.

## Quick Start

```bash
npm install
npm run dev
```

- **Interactive Egress Wire Dissector (`FenceGate.tsx`)**: Added captured wire payload inspection, rule IDs, and live `SIGN ACK` / `RE-FREEZE` controls.
- **Engineering Workbenches (`HardProblemsTrack.tsx`)**: Upgraded horizontal velocity-skewed reel with causal WAL replay tables, 0.9ms egress pipeline breakdown, and live `git diff3` vs AST merge output.
- **CI Chaos Verification Matrix (`ProofMosaic.tsx`) & Startup Ship Bar (`InstallFooter.tsx`)**: Deterministic seeds/durations, live CI runner output, multi-package-manager install tabs (`SH`, `BREW`, `CARGO`), and Open-Source Core vs Cloud Shadow tiers.
