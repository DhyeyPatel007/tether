# Tether — Light-Theme SaaS Dashboard

Production-ready React + TypeScript + Vite + Tailwind CSS + GSAP + Chart.js startup dashboard for **Tether** (protocol-level persistence for unmodified local and browser agents).

## Quick Start

```bash
npm install
npm run dev
```

## Highlights
- **Light-Theme Startup Aesthetic**: Restrained 3-colour palette (Pure White/Alabaster, Deep Forest Emerald `#059669`, Warm Amber `#D97706`, Obsidian Ink `#0F172A`).
- **Premium Typography (Zero Monospace)**: `Plus Jakarta Sans` + `Inter` with tabular numerals.
- **60fps Motion Graphics Explainer Video**: 4-chapter interactive vector motion-graphics player with scrubber, speed control, and synthesized Web Audio cues.
- **Custom Isometric Visuals & Chart.js Infographics**: Bundled under `public/images/` plus live latency and safety-split charts.
